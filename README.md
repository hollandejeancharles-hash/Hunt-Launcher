# Hunt Launcher

Téléchargez [Hunt Launcher pour Windows](https://github.com/hollandejeancharles-hash/Hunt-Launcher/releases/latest/download/Hunt.Launcher.Windows.exe).

Il installe Project Hunt, vérifie les mises à jour et conserve vos réglages. Aucun compte requis pour jouer. Windows 10/11 64 bits, carte graphique compatible Vulkan.

Les sources de développement restent dans un dépôt privé. Ce dépôt contient uniquement les téléchargements du jeu.
